## 📖 簡介

原神的「月諭聖牌」需要玩家之間互相交換才能集滿圖鑑，但要在茫茫玩家中找到「剛好你缺的牌我有、我缺的牌你有」的對象並不容易。

**月諭聖牌交換站**讓玩家只要註冊一個帳號，就能同時管理多個原神 UID 底下的聖牌「多餘 / 缺少」狀態，並透過自動比對，快速找到能互相交換卡牌的旅行者！

### ✨ 為什麼使用這個平台？
* 🗂️ **多 UID 獨立管理**：為每個原神 UID 分別登記「多餘可換」與「缺少徵求」的聖牌。
* ⚡ **精準自動比對**：一鍵搜尋全站玩家，找出雙向都能互補的交換對象。
* 🌍 **伺服器篩選機制**：依伺服器（*Europe / America / Asia / TW, HK, MO*）篩選，避免找到跨服無法交易的對象。
* 🔒 **彈性公開聯絡方式**：選填聯絡方式（*Discord、X 等*），只有你自己決定要不要公開。

---

## 🚀 主要功能

* **會員系統**：支援快速註冊、登入與登出。並且可新增多個原神 UID，各自獨立設定卡牌狀態。
* **聖牌狀態設定**：每張聖牌可標記為 `未設定` / `多餘` / `缺少` 三種狀態之一。
* **交換媒合搜尋**：**不需登入即可搜尋！** 可透過「我想要的牌」、「我多出的牌」與「伺服器」進行精準匹配；也可不設條件瀏覽全站清單。點擊卡牌圖示可放大預覽圖片與名稱。
* **跨服與多語言**：支援 *Europe / America / Asia / TW, HK, MO* 伺服器，提供中 / 英 / 日 / 韓文介面切換。
* **快速複製需求文字**：設定完卡牌狀態後，可快速複製需求文字，同步在社交媒體上尋找可交換的旅行者，多管齊下增加效率。

## 📖 使用指南

#### 1. 註冊帳號
點擊右上角 「註冊」，輸入帳號與密碼（需再次輸入確認）即可完成註冊。

#### 2. 新增原神 UID
登入後進入 「個人頁面」，在「新增原神 UID」欄位輸入你的原神 UID。

#### 3. 設定聖牌狀態
點選列表中要設定的 UID 進入圖鑑頁面，針對每張聖牌進行設定：

+ 未設定：你沒有多餘也不缺少

+ 多餘：你有多的，願意換出

+ 缺少：你正在徵求這張

 設定完成後請記得點擊 「儲存變更」。

#### 4. 搜尋交換對象
回到首頁，展開 「尋找交換對象」，可依需求選擇條件：

+ 我想要的牌：尋找有這些牌可以換給你的人

+ 我多出的牌：尋找正在徵求這些牌的人

+ 伺服器：選擇 Europe / America / Asia / TW, HK, MO（不選則不限伺服器）

條件可任意組合，點擊搜尋結果中的卡牌圖示可放大預覽圖片與名稱。

#### 5. 編輯個人資料
點擊右上角帳號選單的 「編輯個人資料」，可修改：

+ Email（選填，用於忘記密碼時重設）

+ 聯絡方式（選填，填寫後才會公開在交換搜尋結果中）

+ 修改密碼
